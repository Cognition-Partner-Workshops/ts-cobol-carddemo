CardDemo Migration Plan

Mainframe COBOL to Java Spring Boot Microservices with MongoDB and React

Executive Summary

This document outlines the migration strategy for converting the CardDemo mainframe COBOL application to a modern Java Spring Boot microservices architecture with MongoDB and React frontend. The migration transforms legacy VSAM files to MongoDB collections, CICS transactions to REST APIs, and BMS screens to React components.

Migration Steps

  1. Set up Spring Boot project structure with Maven
  2. Create MongoDB document models based on COBOL copybooks
  3. Implement repositories and services for all entities
  4. Create REST controllers with proper API endpoints
  5. Implement JWT authentication and authorization
  6. Build React frontend with TypeScript and Tailwind CSS
  7. Test all functionality end-to-end
  8. Deploy and validate in production environment

Business Logic Migration

Sign-on Logic (COSGN00C → AuthService)

  • Validate user credentials against users collection
  • Generate JWT token on successful authentication
  • Return user type (ADMIN/USER) for role-based access

Account View (COACTVWC → AccountService)

  • Read account by ID from accounts collection
  • Join with customer data via cardXrefs
  • Return formatted account details

Transaction Processing (COTRN02C → TransactionService)

  • Validate card number exists
  • Validate account is active
  • Create transaction record
  • Update account balance

Bill Payment (COBIL00C → TransactionService)

  • Read account current balance
  • Create payment transaction
  • Update account balance to zero
