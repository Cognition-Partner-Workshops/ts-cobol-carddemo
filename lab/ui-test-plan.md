# UI test plan - replay lab page

Page: `http://127.0.0.1:8090/`, started with `make lab` and driven in Chrome on the session machine with
mouse and keyboard, as a presenter would. Calls to the server's endpoints from a shell do not count as a
check. Reference values come from `make lab-gate` run in a terminal on the same checkout (its output and
its exit code) and from files of the repository; each row says which.
The same rows are automated in `lab/e2e/test_lab_page.py` (`make lab-e2e`), one test per row.

Result and evidence are filled in after the run; a row that was not run says so.
The plan has ten rows since the gate also fails on a violated rule (row 7 changed, row 10 added, rows 2 and 5 extended).
The results below are the fourth run of the whole plan (see "Runs" at the end).
