The stream is one batch job, INTCALC, with one step that runs CBACT04C. It reads the transaction-category balances, looks up the account, the card cross-reference and the disclosure-group rate, writes one interest transaction per balance with a non-zero rate to a new generation of SYSTRAN, and rewrites the account balance. app/jcl/INTCALC.jcl:20 app/cbl/CBACT04C.cbl:188-222

The posting chain (POSTTRAN, TRANREPT) is not part of this stream; its jobs appear only as outside-stream users of the same datasets. No target code is produced in this step.
